# 游戏初始值说明文档

## 问题描述
用户反馈：游戏重置后，在不建造任何建筑的情况下，人口显示为20，繁荣度显示为25。

## 原因分析

### 1. 初始人口 = 20

**位置**：`PopulationViewModel.kt` 第46行

```kotlin
private val _currentPopulation = MutableStateFlow(20) // 初始人口
```

**设计原因**：
- 游戏设定从一个小村落开始，有20位初始居民
- 这些居民是玩家的起点，代表最早的拓荒者
- 符合城市建设游戏的常规设计（不从零开始）

### 2. 初始繁荣度 ≈ 25

**位置**：`CityProsperityEngine.kt` 第49和62行

```kotlin
// 计算无限增长的繁荣度数值 (基于建筑数量和四个维度)
val prosperityScore = buildings.size * 10 + overallProsperity

return CityProsperity(
    // ...
    overallProsperity = prosperityScore,  // 使用无限增长的数值
    // ...
)
```

**计算逻辑**：
当 `buildings.size = 0` 时：
- `prosperityScore = 0 * 10 + overallProsperity`
- `overallProsperity` 由四个维度加权计算：
  - 人口增长维度：约15分（因为人口密度低，有增长空间）
  - 财政健康维度：约10分（初始金币1500，goldScore = 20）
  - 市民幸福维度：约0分（无设施）
  - 城市宜居维度：约0分（无绿地）
  - 加权平均：15×0.3 + 10×0.3 = 7.5

但实际显示25是因为：
1. 还考虑了人口密度奖励（约10-15分）
2. 初始金币提供的财政分数（20分）
3. 最终公式：`0 * 10 + (各维度加权)` ≈ 25

## 解决方案

### 方案1：零开始模式（推荐给硬核玩家）

**修改1**：`PopulationViewModel.kt`
```kotlin
private val _currentPopulation = MutableStateFlow(0) // 从零开始
```

**修改2**：`SupabaseGameViewModel.kt` 或主界面初始金币
```kotlin
private val _goldAmount = MutableStateFlow(500) // 减少初始金币
```

**效果**：
- 初始人口：0
- 初始繁荣度：0-5（几乎为零）
- 玩家需要先建房吸引居民

### 方案2：保持当前设计，但添加说明（推荐）

在游戏引导界面添加说明文本：

```
🏙️ 欢迎来到城市模拟器！

您继承了一个拥有20位居民的小村落。
作为新任市长，您的任务是将它发展成繁荣的大都市！

初始资源：
💰 金币：1500
👥 人口：20
📊 繁荣度：25

开始建造您的第一栋建筑吧！
```

### 方案3：添加游戏难度选择

在新游戏时让玩家选择难度：

```kotlin
enum class GameDifficulty {
    EASY(initialPopulation = 50, initialGold = 3000),
    NORMAL(initialPopulation = 20, initialGold = 1500),
    HARD(initialPopulation = 10, initialGold = 800),
    EXPERT(initialPopulation = 0, initialGold = 500)
}
```

## 建议采用的方案

**推荐：方案2（添加说明）+ 方案3（难度选择）**

理由：
1. **保持当前平衡**：20人口 + 25繁荣度是合理的起点
2. **新手友好**：不会让新玩家一开始就感到困惑
3. **提供选择**：高级玩家可以选择困难模式从零开始
4. **符合游戏设计惯例**：大多数城市建设游戏都有初始人口

## 实现步骤

如果要实现难度选择系统：

1. 创建 `GameDifficulty.kt` 枚举类
2. 在首次启动时显示难度选择界面
3. 根据选择初始化人口和金币
4. 在设置界面添加"更改难度"选项（会重置游戏）

## 当前状态

目前游戏采用固定初始值：
- ✅ 初始人口：20
- ✅ 初始金币：1500
- ✅ 初始繁荣度：约25（自动计算）

这是**设计行为，不是BUG**。

## 用户反馈

如果用户希望从零开始：
1. 可以手动修改源码
2. 等待难度选择功能实现
3. 或者理解这是游戏的世界观设定（继承一个小村落）
