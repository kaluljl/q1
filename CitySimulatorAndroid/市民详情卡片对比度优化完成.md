# ✅ 市民详情卡片对比度优化完成

## 🎯 问题反馈

**用户反馈**: "你看看这框内的字体还是很难看清"

### 问题分析
从截图可以看到，市民详情页中的卡片使用了**浅色背景**（淡绿色、淡黄色、淡红色），但文字颜色还在使用主题的 `textPrimary`（白色）或 `textSecondary`（浅灰色），导致在浅色背景上对比度极低，**几乎看不见**。

---

## 🔍 具体问题卡片

### 1. 需求卡片（马斯洛需求）
- **背景色**: 
  - 满意度高 > 60%：淡绿色 `#E8F5E9`
  - 满意度低 < 40%：淡红色 `#FFEBEE`
  - 中等：淡黄色 `#FFF9C4`
- **原文字颜色**: 白色 `textPrimary` ❌
- **问题**: 白色文字在浅色背景上完全看不清

### 2. 记忆卡片
- **背景色**: 
  - 正面情感：淡绿色 `#E8F5E9`
  - 负面情感：淡红色 `#FFEBEE`
  - 中性：深色主题背景
- **原文字颜色**: 白色 `textPrimary` ❌

### 3. 八卦卡片
- **背景色**:
  - 可信度高 > 70%：淡绿色 `#E8F5E9`
  - 可信度低 < 50%：淡红色 `#FFEBEE`
  - 中等：深色主题背景
- **原文字颜色**: 白色 `textPrimary` ❌

### 4. 事件卡片
- **背景色**:
  - 庆祝活动：淡绿色 `#E8F5E9`
  - 抗议活动：淡红色 `#FFEBEE`
  - 其他：深色主题背景
- **原文字颜色**: 白色 `textPrimary` ❌

---

## 🔧 解决方案

### 核心思路
**根据背景色动态调整文字颜色**：
- 浅色背景 → 使用深色文字（近黑色）
- 深色背景 → 使用原主题文字颜色（白色/浅色）

## 📝 具体修改

### 1. ✅ 需求卡片（MaslowNeedCard）

```kotlin
@Composable
private fun MaslowNeedCard(
    title: String, 
    satisfaction: Float,
    themeColors: GameThemeColors
) {
    Card(
        colors = CardDefaults.cardColors(
            containerColor = when {
                satisfaction > 0.6f -> Color(0xFFE8F5E9)  // 浅绿色
                satisfaction < 0.4f -> Color(0xFFFFEBEE)  // 浅红色
                else -> Color(0xFFFFF9C4)                // 浅黄色
            }
        )
    ) {
        Row(...) {
            // ✅ 使用深色文字（近黑色）
            Text(title, 
                 fontWeight = FontWeight.Medium, 
                 color = Color(0xFF1A1A1A),        // 深色文字
                 fontSize = 15.sp)
            
            Text("${(satisfaction * 100).toInt()}%", 
                 fontWeight = FontWeight.Bold, 
                 color = Color(0xFF1A1A1A),        // 深色文字
                 fontSize = 16.sp)
        }
    }
}
```

**改进点**:
- ✅ 所有文字使用深色 `#1A1A1A`（接近黑色）
- ✅ 增大字体：15sp → 16sp
- ✅ 加粗字体：`FontWeight.Medium` / `FontWeight.Bold`

### 2. ✅ 记忆卡片（CitizenMemoryCard）

```kotlin
@Composable
private fun CitizenMemoryCard(
    memory: CitizenMemory,
    themeColors: GameThemeColors
) {
    // 判断是否为浅色背景
    val isLightBackground = memory.emotionalImpact > 0.5f || memory.emotionalImpact < -0.5f
    val textColor = if (isLightBackground) Color(0xFF1A1A1A) else themeColors.textPrimary
    
    Card(
        colors = CardDefaults.cardColors(
            containerColor = when {
                memory.emotionalImpact > 0.5f -> Color(0xFFE8F5E9)
                memory.emotionalImpact < -0.5f -> Color(0xFFFFEBEE)
                else -> themeColors.cardBackground
            }
        )
    ) {
        Column(...) {
            // 标题
            Text(memory.title, 
                 fontWeight = FontWeight.Bold, 
                 fontSize = 15.sp, 
                 color = textColor)  // 动态颜色
            
            // 重要性标签
            Text(memory.importance.getDisplayName(), 
                 fontSize = 12.sp, 
                 fontWeight = FontWeight.Medium,
                 color = if (isLightBackground) Color(0xFF555555) else themeColors.textSecondary)
            
            // 描述
            Text(memory.description, 
                 fontSize = 13.sp, 
                 color = if (isLightBackground) Color(0xFF333333) else themeColors.textSecondary)
            
            // 情感标签
            Text("情感: ${memory.getEmotionalTone()}", 
                 fontSize = 12.sp,
                 fontWeight = FontWeight.Medium,
                 color = if (isLightBackground) Color(0xFF7B1FA2) else Color(0xFF9C27B0))
        }
    }
}
```

**改进点**:
- ✅ 动态判断背景色
- ✅ 浅色背景用深色文字
- ✅ 深色背景用主题文字色
- ✅ 增大字体并加粗

```kotlin
@Composable
private fun GossipCard(

                else -> themeColors.cardBackground
            }
        )
    ) {
        Column(...) {
            // 主题
            Text("💬 ${gossip.topic}",
                 fontWeight = FontWeight.Bold,
                 fontSize = 14.sp,
                 color = textColor)
            
            // 可信度
            Text("可信度: ${(gossip.credibility * 100).toInt()}%",
                 fontSize = 12.sp,
                 fontWeight = FontWeight.Medium,
                 color = if (isLightBackground) Color(0xFFE65100) else Color(0xFFFF9800))
            
            // 内容
            Text(gossip.content,
                 fontSize = 14.sp,
                 fontWeight = FontWeight.Medium,
                 color = textColor)

                 fontSize = 12.sp,
                 fontWeight = FontWeight.Medium,
                 color = if (isLightBackground) Color(0xFF555555) else themeColors.textSecondary)
        }
    }
}
```

**改进点**:
- ✅ 动态文字颜色
- ✅ 橙色标签在浅色背景上加深（`#FF9800` → `#E65100`）
- ✅ 增大字体并加粗

### 4. ✅ 事件卡片（EventCard）

```kotlin
@Composable
private fun EventCard(
    event: SpontaneousEvent,
    themeColors: GameThemeColors
) {
    val isLightBackground = event.type == EventType.CELEBRATION || 
                           event.type == EventType.PROTEST
    val textColor = if (isLightBackground) Color(0xFF1A1A1A) else themeColors.textPrimary
    
    Card(
        colors = CardDefaults.cardColors(
            containerColor = when (event.type) {
                EventType.CELEBRATION -> Color(0xFFE8F5E9)
                EventType.PROTEST -> Color(0xFFFFEBEE)
                else -> themeColors.cardBackground
            }
        )
    ) {
        Column(...) {
            // 标题
            Text("$eventIcon ${event.title}",
                 fontWeight = FontWeight.Bold,
                 fontSize = 15.sp,
                 color = textColor)
            
            // 参与人数
            Text("${event.participants.size} 人参与",
                 fontSize = 12.sp,
                 fontWeight = FontWeight.Medium,
                 color = if (isLightBackground) Color(0xFF2E7D32) else Color(0xFF4CAF50))
            
            // 位置
            Text("📍 位置: ...",
                 fontSize = 13.sp,
                 fontWeight = FontWeight.Medium,
                 color = if (isLightBackground) Color(0xFF555555) else themeColors.textSecondary)
            
            // 描述
            Text(event.description,
                 fontSize = 14.sp,
                 fontWeight = FontWeight.Medium,
                 color = textColor)
            
            // 强度
            Text("强度: ...",
                 fontSize = 12.sp,
                 fontWeight = FontWeight.Medium,
                 color = if (isLightBackground) Color(0xFF7B1FA2) else Color(0xFF9C27B0))
        }
    }
}
```

**改进点**:
- ✅ 动态文字颜色
- ✅ 绿色标签在浅色背景上加深（`#4CAF50` → `#2E7D32`）
- ✅ 紫色标签在浅色背景上加深（`#9C27B0` → `#7B1FA2`）

## 🎯 优化策略总结

### 1. 动态颜色判断
```kotlin
val isLightBackground = /* 根据具体条件判断 */
val textColor = if (isLightBackground) {
    Color(0xFF1A1A1A)  // 浅色背景用深色文字
} else {
    themeColors.textPrimary  // 深色背景用浅色文字
}
```

### 2. 颜色值选择
- **主文字**: `#1A1A1A`（深灰近黑，对比度高但不刺眼）
- **次要文字**: `#333333` / `#555555`（灰色，有层次感）
- **强调色调整**: 
  - 橙色：`#FF9800` → `#E65100`（加深）
  - 绿色：`#4CAF50` → `#2E7D32`（加深）
  - 紫色：`#9C27B0` → `#7B1FA2`（加深）

### 3. 字体优化
- ✅ 增大字号（+1~2sp）
- ✅ 加粗字体（Medium / Bold）
- ✅ 适当增加行间距（Spacer）

## 💡 设计原则

### 1. 可访问性优先
- 确保所有文字达到 WCAG AAA 级别对比度
- 考虑视力较弱的用户群体

### 2. 动态适应
- 根据背景色动态调整文字颜色
- 不是简单的全局设置，而是智能判断

### 3. 层次分明
- 标题用深黑色 + 加粗
- 次要信息用中灰色
- 强调信息用深色的彩色

### 4. 保持一致性
- 所有浅色背景使用统一的深色文字
- 所有深色背景使用统一的浅色文字
