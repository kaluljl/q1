用户反馈：**"字体还是看不清"**

## 🎯 新的优化策略

### 方案1：增加文字描边/阴影 ✨
为所有文字添加深色描边，大幅提升对比度

### 方案2：调亮卡片背景 ✨
让卡片背景更亮，增加文字与背景的对比

### 方案3：增大字体大小 ✨
全局提升字体大小，让文字更容易看清

### 方案4：更激进的文字颜色 ✨
使用更明亮的文字颜色

## 📊 具体实施

### 1. 文字描边/阴影效果
```kotlin
// 为重要文字添加阴影
Text(
    text = "标题文字",
    style = TextStyle(
        shadow = Shadow(
            color = Color.Black,
            offset = Offset(1f, 1f),
            blurRadius = 2f
        )
    )
)
```

### 2. 调亮卡片背景
```kotlin
// 当前（太暗）
cardBackground = Color(0xFF2C2C3E)  // 暗灰色

// 优化后（更亮）
cardBackground = Color(0xFF404050)  // 明显更亮
```

### 3. 增大字体
```kotlin
// 当前
fontSize = 14.sp  // 正文
fontSize = 16.sp  // 标题

// 优化后
fontSize = 16.sp  // 正文 (+2sp)
fontSize = 18.sp  // 标题 (+2sp)
```

### 4. 文字颜色加强
```kotlin
// 当前
textSecondary = Color(0xFFCCCCCC)  // 80% 白

// 优化后
textSecondary = Color(0xFFEEEEEE)  // 93% 白
```

## 🔧 哪种方案最有效？

### 推荐组合方案
**方案 2 + 方案 4**：调亮背景 + 保持纯白文字

**理由**：
- ✅ 最简单直接
- ✅ 性能最好（无需渲染阴影）
- ✅ 视觉效果最明显
- ✅ 不改变字体大小（保持布局）
