## 🔧 技术实现

### 主要修改

#### 1. 获取当前主题
```kotlin
val currentTheme = ThemeManager.getCurrentTheme()
```

#### 2. 应用主题到UI组件

**TopAppBar**
```kotlin
colors = TopAppBarDefaults.topAppBarColors(
    containerColor = currentTheme.primary
)
```

**TabRow**
```kotlin
TabRow(
    containerColor = currentTheme.cardBackground,
    contentColor = currentTheme.textPrimary
)
```

**Background**
```kotlin
.background(getThemeBackgroundBrush(currentTheme))
```

**Text**
```kotlin
Text(
    text = "内容",
    color = currentTheme.textPrimary  // 或 textSecondary
)
```

**Card**
```kotlin
Card(
    colors = CardDefaults.cardColors(
        containerColor = currentTheme.cardBackground
    )
)
```

#### 3. 传递主题参数
所有子组件都接收 `themeColors` 参数：
```kotlin
private fun PersonalityTab(
    personality: PersonalityTraits,
    scrollState: ScrollState,
    themeColors: GameThemeColors  // 主题参数
)
```
